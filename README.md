## Χαρακτηριστικά

Το αποθετήριο μεταφέρει τον προφορικό λόγο των 55+ ωρών διαλέξεων σε ευανάγνωστο γραπτό κείμενο (Markdown & HTML):

- **21 ολοκληρωμένα κεφάλαια** που διατηρούν τη ροή, τα παραδείγματα και το προσωπικό αφηγηματικό ύφος της Μαρίας Ευθυμίου.
- **105 σύνδεσμοι χρονοσήμανσης (timestamps)** μέσα στο κείμενο που οδηγούν απευθείας στο αντίστοιχο σημείο του βίντεο στο YouTube.
- **72 αυθεντικά μουσειακά τεκμήρια και χάρτες** (Public Domain / Wikimedia Commons) με ιστορικές λεζάντες.
- **Πλήρεις απομαγνητοφωνήσεις** (>180.000 λέξεις) στον φάκελο [`transcripts/`](transcripts/) για γρήγορη αναζήτηση.
- **Ελαφρύς Web Reader** χωρίς εξωτερικές εξαρτήσεις (3 θέματα ανάγνωσης, αναζήτηση, offline λειτουργία).

## 💻 Τοπική Ανάγνωση

Μπορείτε να διαβάσετε τα κείμενα απευθείας στο GitHub μέσω του φακέλου [`chapters/`](chapters/) ή να εκκινήσετε τον Web Reader τοπικά:

```bash
git clone https://github.com/nikoskoutr/efthimiou-lessons.git
cd efthimiou-lessons
python3 -m http.server 8000
```

Ανοίξτε τον φυλλομετρητή σας στο `http://localhost:8000`.

**Συντομεύσεις Πληκτρολογίου στον Web Reader:**
- `Alt + ⬅` / `Alt + ➡` : Προηγούμενο / Επόμενο κεφάλαιο
- `T` : Πίνακας περιεχομένων & αναζήτηση
- `D` : Εναλλαγή θέματος (Πάπυρος / Σέπια / Νύχτα)
- `+` / `-` : Μέγεθος γραμματοσειράς
