# Μικρά Μαθήματα για έναν Μεγάλο Κόσμο
### Μαρία Ευθυμίου — Ψηφιακό Βιβλίο & Διαδραστικός Αναγνώστης

Μια ολοκληρωμένη ψηφιακή έκδοση και διαδραστικός αναγνώστης για τον εμβληματικό κύκλο 21 πανεπιστημιακών διαλέξεων της καθηγήτριας Ιστορίας του ΕΚΠΑ **Μαρίας Ευθυμίου** (*Megaron Plus & BLOD*).

---

## 🌟 Χαρακτηριστικά Έργου

- **21 Πλήρη Μαθήματα / Κεφάλαια:** Από την Παλαιολιθική Εποχή και τη Γεωργική Επανάσταση έως τον 21ο αιώνα, τον Ψυχρό Πόλεμο και τη σύγχρονη εποχή.
- **51.000+ Λέξεις (Markdown & HTML):** Πλούσια ιστορική τεκμηρίωση με απόλυτη αμφίδρομη ισοτιμία (100% parity) μεταξύ κειμένων `.md` και αρχείων `.html`.
- **76 Πλαίσια Αυθεντικού Λόγου («Η Ματιά της Μαρίας»):** Ζωντανά αποσπάσματα διδασκαλίας με άμεσα, κλικαρίσιμα YouTube timestamps ακριβείας.
- **72 Αυθεντικά Ιστορικά Τεκμήρια:** Αρχαιολογικά ευρήματα, βυζαντινά ψηφιδωτά, ιστορικοί χάρτες και πίνακες τέχνης (μηδενική χρήση AI εικόνων).
- **Σύγχρονη Διεπαφή & Mobile Reader:**
  - Πλήρως αποκριτικό συρτάρι πλοήγησης (Mobile Drawer) με υποστήριξη αφής (Touch Swipes).
  - 3 επιλεγμένα θέματα ανάγνωσης: **Πάπυρος** (Parchment), **Σέπια** (Sepia), **Νύχτα** (Dark Mode).
  - Προ-ενυδάτωση `<head>` για αποφυγή του λευκού αναβοσβήματος (Anti-FOUC).
  - Αυξομείωση μεγέθους γραμματοσειράς με αναλογική διατήρηση των responsive breakpoints.
  - Ζωντανή αναζήτηση στον Πίνακα Περιεχομένων με αυτόματη εξομάλυνση τόνων και τελικού σίγμα (`ς` ↔ `σ`).
  - Μπάρα προόδου ανάγνωσης (60/120fps) και υπολογισμός εκτιμώμενου χρόνου ανάγνωσης ανά κεφάλαιο.

## 🚀 Τοπική Εκκίνηση (Local Server)

Για να διαβάσετε το βιβλίο σε οποιαδήποτε συσκευή (Desktop, Tablet, Κινητό) στο τοπικό σας δίκτυο:

```bash
# Μετάβαση στον φάκελο
cd ~/efthimiou-lessons

# Εκκίνηση τοπικού web server
python3 -m http.server 8000
```

- **Από τον υπολογιστή:** [http://localhost:8000](http://localhost:8000)
- **Από κινητό/tablet στο ίδιο Wi-Fi:** `http://<YOUR_LOCAL_IP>:8000`
