## 🎯 Τι είναι αυτό το έργο;

Ο εμβληματικός κύκλος διαλέξεων **«19 Μικρά Μαθήματα για έναν Μεγάλο Κόσμο»** (ο οποίος ολοκληρώθηκε σε **21 διαλέξεις** συνολικής διάρκειας άνω των **55 ωρών**) της καθηγήτριας **Μαρίας Ευθυμίου** στο Μέγαρο Μουσικής Αθηνών συνιστά ένα από τα πολυτιμότερα δημόσια μορφωτικά αγαθά της σύγχρονης Ελλάδας. Οι διαλέξεις διατίθενται ελεύθερα στο κοινό μέσω του [**BLOD (Bodossaki Lectures on Demand)**](https://www.blod.gr/) και του [**YouTube**](https://www.youtube.com/).

Το παρόν αποθετήριο (`efthimiou-lessons`) δημιουργήθηκε ως ένα **ανοικτό, μη κερδοσκοπικό Συνοδευτικό Εγχειρίδιο Μελέτης (Study Companion) και Διαδραστικός Αναγνώστης**, σχεδιασμένο ειδικά για όσους παρακολουθούν ή μελετούν τις διαλέξεις αυτές.

Στόχος του έργου δεν είναι να υποκαταστήσει τη μοναδική, χαρισματική προφορική διδασκαλία της Μαρίας Ευθυμίου, αλλά να λειτουργήσει ως **ο απόλυτος ψηφιακός συνοδοιπόρος** που προσφέρει στον θεατή και τον αναγνώστη όσα δεν μπορεί να προσφέρει ένα απλό βίντεο:

1. **Δομημένη Ιστορική Αφήγηση (122.245 λέξεις):** Πλήρης μετατροπή του προφορικού λόγου σε 21 άρτια διαρθρωμένα κεφάλαια, διατηρώντας ακέραιο το αυθεντικό «ύφος Ευθυμίου»: τον ιστορικό ενεστώτα, τα διαυγή παραδείγματα, τις παιδαγωγικές αναλογίες, τις συνδέσεις μικρο-ιστορίας με τη μακρο-ιστορία και το αφοπλιστικό της χιούμορ.
2. **Άμεση Σύνδεση Κειμένου & Βίντεο:** **105 διαδραστικά πλαίσια** (*«Η Ματιά της Μαρίας»* / `box-maria`) με επαληθευμένες χρονοσημάνσεις (timestamps) που ανοίγουν το βίντεο στο YouTube ακριβώς στο αντίστοιχο δευτερόλεπτο της διάλεξης.
3. **Οπτική & Χαρτογραφική Πλαισίωση:** **72 αυθεντικά μουσειακά και αρχαιολογικά τεκμήρια**, ιστορικοί χάρτες και περίοδοι μικρογραφίες (με 0% εικόνες AI), συνοδευόμενα από αναλυτικές ιστορικές λεζάντες.
4. **Συνθετικά Εργαλεία Εμπέδωσης:** Χρονολογικά αναπτύγματα (Timeline Ribbons) στην αρχή κάθε κεφαλαίου, συγκριτικοί πίνακες, εννοιολογικοί άξονες και φιλοσοφικοί αναστοχασμοί κλεισίματος.
5. **Πλήρες Αρχείο Απομαγνητοφωνήσεων (>180.000 λέξεις):** Λέξη προς λέξη απομαγνητοφώνηση και των 21 διαλέξεων στον φάκελο [`transcripts/`](transcripts/) για άμεση αναζήτηση και ακαδημαϊκή αναφορά.

## 🧭 Πώς να χρησιμοποιήσετε τον Οδηγό παράλληλα με τις Διαλέξεις

Το εγχειρίδιο έχει κατασκευαστεί για **υβριδική, πολυεπίπεδη μελέτη** παράλληλα με τις βιντεοσκοπημένες διαλέξεις:

```
┌─────────────────────────────────┐       ┌─────────────────────────────────┐
│     ΔΗΜΟΣΙΑ ΔΙΑΛΕΞΗ (VIDEO)     │       │   ΣΥΝΟΔΕΥΤΙΚΟΣ ΑΝΑΓΝΩΣΤΗΣ (WEB) │
│         YouTube / BLOD          │       │      Markdown / HTML Reader     │
├─────────────────────────────────┤       ├─────────────────────────────────┤
│ • 55+ Ώρες Προφορικής Παράδοσης │ ◄───► │ • Δομημένο Κείμενο & Ενότητες   │
│ • Χαρισματική Ρητορική & Πάθος  │       │ • ⏳ Χρονολογικό Ανάπτυγμα      │
│ • Αυθόρμητοι Διάλογοι Αίθουσας  │  Click│ • 💬 105 Timestamps Μαρίας      │
│                                 │  ◀─── │ • 🏛️ 72 Μουσειακά Τεκμήρια     │
│ [▶ 01:14:22] «Η Ματιά Μαρίας»   │       │ • 🕊️ Φιλοσοφικός Αναστοχασμός   │
└─────────────────────────────────┘       └─────────────────────────────────┘
```

* 🎧 **1. Παρακολούθηση της Διάλεξης:** Ξεκινήστε τη βιντεοσκοπημένη διάλεξη στο YouTube ή το BLOD.
* 📖 **2. Συνοδευτική Ανάγνωση:** Ανοίξτε ταυτόχρονα το αντίστοιχο κεφάλαιο στον [Διαδραστικό Αναγνώστη](index.html) (στον υπολογιστή, το tablet ή το κινητό σας). Συμβουλευτείτε το **Χρονολογικό Ανάπτυγμα** στην κορυφή ως πυξίδα.
* ⏱️ **3. Διαδραστικά Άλματα («Η Ματιά της Μαρίας»):** Όταν συναντάτε ένα πλαίσιο αποφθέγματος με το κόκκινο έμβλημα χρόνου (π.χ. `[▶ 22:15]`), πατώντας το μεταφέρεστε απευθείας στο ακριβές σημείο της διάλεξης όπου η καθηγήτρια αναπτύσσει τη συγκεκριμένη σκέψη.
* 🏛️ **4. Μελέτη των Ιστορικών Τεκμηρίων:** Εξετάστε τα αρχαιολογικά ευρήματα, τα χειρόγραφα και τους χάρτες σε υψηλή ανάλυση ακριβώς τη στιγμή που η διάλεξη αναφέρεται σε αυτά.
* 🔍 **5. Αναζήτηση στις Πρωτογενείς Απομαγνητοφωνήσεις:** Χρειάζεστε μια συγκεκριμένη φράση, αστεϊσμό ή ανάλυση; Αναζητήστε απευθείας στα αρχεία [`transcripts/ch01.md` έως `ch21.md`](transcripts/).
* 🕊️ **6. Αναστοχασμός & Σύνθεση:** Κάθε μάθημα ολοκληρώνεται με τη συνθετική παράγραφο «Αναστοχασμός», η οποία συμπυκνώνει τα μεγάλα ηθικά, γεωπολιτικά και ιστορικά διδάγματα της εκάστοτε εποχής.

## 🖥️ Τεχνική Αρχιτεκτονική & Διαδραστικός Αναγνώστης

Ο **Διαδραστικός Αναγνώστης** είναι κατασκευασμένος με πρότυπη HTML5, σύγχρονο responsive CSS3 και Vanilla JavaScript, με **μηδενικές εξωτερικές εξαρτήσεις (Zero Dependencies)**, εξασφαλίζοντας αστραπιαία φόρτωση, πλήρη λειτουργία εκτός σύνδεσης (offline) και διαχρονική ανθεκτικότητα:

* 🎨 **3 Τυπογραφικά Θέματα Ανάγνωσης:**
  * **Πάπυρος (Parchment):** Θερμή παλέτα βιβλίου για άνετη ημερήσια ανάγνωση.
  * **Σέπια (Sepia):** Χαμηλή αντίθεση για ξεκούραστη πολύωρη μελέτη.
  * **Νύχτα (Dark Mode):** Σκούρο φόντο με προσεκτικά βαθμονομημένη αντίθεση για νυχτερινή μελέτη.
* ⚡ **Προ-ενυδάτωση `<head>` (Anti-FOUC Script):** Το επιλεγμένο θέμα και μέγεθος γραμματοσειράς εφαρμόζονται πριν από τη σχεδίαση της σελίδας, εξαλείφοντας πλήρως το δυσάρεστο λευκό αναβόσβημα κατά την αλλαγή κεφαλαίων.
* 📱 **Mobile-First Σχεδιασμός & Χειρονομίες Αφής (Touch Gestures):** Πλήρως αποκριτικό συρτάρι πλοήγησης (Sidebar Drawer) με υποστήριξη αφής (Swipe gestures) και αυτόματη προσαρμογή ασφαλών ζωνών (Safe-area-inset).
* 🔍 **Έξυπνη Αναζήτηση στον Πίνακα Περιεχομένων:** Ζωντανό φιλτράρισμα και των 21 κεφαλαίων με αυτόματη εξομάλυνση τόνων και τελικού σίγμα (`ς` ↔ `σ`).
* ⌨️ **Πλήρης Έλεγχος από το Πληκτρολόγιο:**

| Πλήκτρο | Λειτουργία |
| :--- | :--- |
| `Alt` + `➡` / `Alt` + `⬅` | Μετάβαση στο Επόμενο / Προηγούμενο Κεφάλαιο |
| `T` ή `τ` | Άνοιγμα / Κλείσιμο Συρταριού Περιεχομένων |
| `D` ή `δ` | Εναλλαγή Θέματος (Πάπυρος ➡ Σέπια ➡ Νύχτα) |
| `+` / `-` | Αύξηση / Μείωση Μεγέθους Γραμματοσειράς |
| `Esc` | Κλείσιμο μενού & καθαρισμός πεδίου αναζήτησης |

## 🚀 Γρήγορη Εκκίνηση (Quickstart)

Μπορείτε να διαβάσετε τα κείμενα απευθείας στο GitHub στον φάκελο [`chapters/`](chapters/) ή να ανοίξετε τον πλήρη **Διαδραστικό Αναγνώστη** στον υπολογιστή, το tablet ή το κινητό σας:

### 1. Κλωνοποίηση του Αποθετηρίου
```bash
git clone https://github.com/nikoskoutr/efthimiou-lessons.git
cd efthimiou-lessons
```

### 2. Τοπική Εκκίνηση (Local Server)
Για βέλτιστη εμπειρία ανάγνωσης και απρόσκοπτη φόρτωση των τοπικών γραμματοσειρών και εικόνων:
```bash
python3 -m http.server 8000
```
* **Στον Υπολογιστή σας:** Ανοίξτε τον φυλλομετρητή στη διεύθυνση [**`http://localhost:8000`**](http://localhost:8000).
* **Στο Κινητό ή το Tablet σας:** Συνδεθείτε στο ίδιο Wi-Fi και ανοίξτε τη διεύθυνση `http://<IP_ΥΠΟΛΟΓΙΣΤΗ>:8000` (π.χ. `http://192.168.1.50:8000`).

### 3. Έλεγχοι Ακεραιότητας (Test Suite)
Για να επαληθεύσετε την 100% ισοτιμία Markdown/HTML, την εγκυρότητα των συνδέσμων YouTube και την αρτιότητα του UI:
```bash
python3 tests/run_all.py
```
